## 🛠️ Tecnologías y Conceptos Aplicados
Durante la resolución de estos ejercicios de revisión se ponen en práctica las siguientes tecnologías y conceptos:
* **PostgreSQL:** Scripts para diseño de esquemas (DDL), manipulación de datos (DML) y consultas de datos (DQL).
* **Bases de Datos Relacionales:** Práctica activa con Triggers, Procedimientos Almacenados, CTEs (Common Table Expressions) y funciones de ventana.
* **Control de Versiones:** Git y GitHub para la gestión del código.
* **Documentación:** Markdown.

## 🚀 Cómo ejecutar los scripts
1. Clona este repositorio en tu entorno local:
   ```bash
   git clone https://github.com/canuxantonio502/reviews_postgresql.git
   ```
2. Abre tu cliente o IDE de bases de datos favorito (como pgAdmin, DBeaver, o la consola de psql).
3. Conéctate a tu servidor local de PostgreSQL.
4. Abre y ejecuta los scripts `.sql` correspondientes a cada carpeta/review para crear las estructuras y probar las consultas.
